# Laboratory Activity 5: Mission 5 – The Cloud Data Engineer

## Mission Overview
In this activity, I studied how Block, File, and Object Storage differ, then set up my own S3-compatible object storage server using MinIO and Docker. I created a storage bucket and uploaded a file to confirm the deployment worked, which mirrored a real cloud data engineering task.

## Objectives
- Explain the differences between Block, File, and Object Storage
- Set up an S3-compatible Object Storage server (MinIO) with Docker
- Reach a cloud service through a web interface using port forwarding
- Create a storage bucket and upload objects (files) to it
- Record cloud storage operations in Markdown
- Keep building a professional GitHub Cloud Computing Portfolio

## Tools Used
- KillerCoda Playground (Ubuntu/Docker environment)
- Docker
- MinIO (S3-compatible object storage server)
- GitHub (portfolio repository)

## Skills Learned
- Telling cloud storage architectures apart and matching each to its best use case
- Running a containerized service in Docker with environment variables
- Connecting to a cloud service by forwarding a specific port
- Making a storage bucket and uploading objects through a web console
- Writing clear technical documentation in Markdown
